How to use this with LLMs?

Lexical Compression: This algorithm removes filler words (stopwords) and replaces verbose phrases with minimal equivalents without breaking tokenizer (BPE) boundaries. It instantly saves ~20-30% tokens.


For Maximum Compression (Semantic SPR): If you want to compress a massive text (like a whole book) into a tiny space for long-term memory, ask an LLM directly using this prompt:

"Analyze the following text and compress it into a Sparse Priming Representation (SPR). Use dense jargon, abbreviations, and minimalist syntax. Ensure that an LLM can flawlessly reconstruct the core knowledge, logic, and factual data from this SPR. Give me ONLY the SPR."

🤖 Connect Your Agents via MCP

We provide a Model Context Protocol (MCP) server so your AI agents can automatically compress text themselves. Because it's an API, the text is never saved by us, but it contributes to the global token savings tally above!

For Claude Desktop

Add this to your claude_desktop_config.json:

{ "mcpServers": { "prompt-compressor": { "command": "python", "args": ["/path/to/TokenCompressor/mcp-server/server.py"] } } }

For Cursor IDE

  1. Open Settings > Features > MCP
  2. Add a new MCP server. Type: stdio
  3. Command: python /path/to/TokenCompressor/mcp-server/server.py
